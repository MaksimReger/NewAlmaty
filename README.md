# Городской контур — Алматы

Статический сайт городского медиа без сборщика и зависимостей. Подходит для GitHub Pages и Vercel.

## Структура

- `index.html` — главная
- `article.html` — универсальная страница статьи с `?id=...`
- `about.html` — о проекте
- `contacts.html` — контакты
- `style.css` — весь дизайн
- `script.js` — новости, поиск, меню и рендер статей
- `assets/images/` — фотографии

## Фотографии Максима

В текущей версии уже установлены две переданные фотографии:

- `assets/images/maxim-main.jpg` — фотография в костюме, используется как основная;
- `assets/images/maxim-2.jpg` — фотография в автомобиле, используется во втором блоке и галерее.

При необходимости дополнительные фотографии можно добавить как `maxim-3.jpg` и `maxim-4.jpg`.

В коде оставлены комментарии:

`<!-- ЗАМЕНИТЕ НА ФОТО МАКСИМА -->`

Когда фотографии будут добавлены, в `script.js` можно заменить placeholder-блоки на обычные `<img>` или оставить текущую систему и добавить CSS/HTML для изображений.

## Как добавить реальное фото

Самый простой вариант — заменить placeholder в `script.js` функцией `placeholder()` на `<img src="assets/images/maxim-main.jpg" alt="Максим Индучный">`. Аналогично используются `maxim-2.jpg` и `maxim-3.jpg`.

## Как добавить новость

В начале `script.js` есть массив `articles`. Добавьте новый объект с:
- `id`
- `cat`
- `date`
- `title`
- `desc`
- `source`
- `url`
- `image`

Для полноценной уникальной статьи добавьте текст в `articleText(id)`.

## Важно

Новости в стартовой версии основаны на открытых публикациях официальных городских источников. Это редакционный пересказ, а не официальный пресс-релиз. Для публикации в интернете желательно дополнительно проверять актуальность каждой новости непосредственно перед размещением.
